# Dashboard Python

Esse Dashboard surgiu como um trabalho para a disciplina de Sistemas de Apoio a Decisão, um Dashboard feito em Python para análise cruzada de dados da crise financeira de 2008 que teve seu início nos EUA e se alastrou rapidamente pelo mundo devido a interconexão dos mercados financeiros globais e do comércio internacional.

O uso é simples:

* A primeira guia tem indicadores dinâmicos que podem ser escolhidos baseados nos períodos trimestrais de 01/1998 a 12/2009. Escolha uma métrica e um data de início e fim para exibição do gráfico.

* A segunda aba mostra gráficos fixos para uma análise cruzada observando fatores e comportamentos que indicariam um estouro iminente.
